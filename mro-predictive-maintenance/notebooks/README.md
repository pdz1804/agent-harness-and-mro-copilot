allows `notebooks/` **or** `reports/` for example predictions and
explanations, and this deliverable uses `reports/` (generated by
`python -m src.pipeline`) plus `docs/demo-evidence.md` (captured, reviewable
output) instead. See:

- `../reports/high_risk_examples.md` -- example high-risk predictions with SHAP
- `../reports/metrics_table.md` -- model comparison table
- `../docs/demo-evidence.md` -- the same evidence, narrated for a non-technical reviewer
