# Agent Harness Console — product context

- **What:** an ops console for running, approving, inspecting and evaluating LLM agents (chat with tool calls, human-in-the-loop approval, traces, evals, dashboards, KB, guardrails).
- **Who:** SRE and on-call engineers, plus the people who build agents. They use it in long sessions on desktop, in daylight offices, and sometimes check approvals from a phone.
- **Mode:** Operate (impeccable). Scanability, consistency and native expectations come before expression. Chat is the flagship surface.
- **Bar:** Linear, Vercel, Raycast, Claude.ai, Langfuse. Crisp, confident and modern. Never generic, never dated.
- **Non-negotiables:**
  - No behaviour regressions: RBAC switcher, SSE streaming, approvals, inspector, palette.
  - Approval is a *state of a tool call*, never a pop-up.
  - Artifacts are shown from real endpoints only, never faked.
  - WCAG AA. `prefers-reduced-motion` is respected.
